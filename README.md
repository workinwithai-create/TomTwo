# TomTwo

Two-bar live tom-fill desk for bedroom producers and AI-music finishers.

Suno and loop DAWs dump from chorus into verse with no handshake. Session players write two live bars of toms so the next section arrives on purpose.

Live samples only — FluidR3 piano, upright bass, nylon guitar, and an acoustic kit from the PreEight sample bank. No oscillators. Audio never leaves the tab.

## Distinct from today and the rest of the line

| Tool | Job |
|------|-----|
| DropFour | Four bars where the **floor hits** after the lift |
| LeadFour | Four bars of **top-line figure** (trumpet / violin) |
| RimFour | Rim-click pocket |
| CongaFour | Conga / bongo pocket |
| CueFour | Count-in so the downbeat lands together |
| BuildFour | Four-bar build into a drop |
| **TomTwo** | Two bars of **toms** so the next section has a door |

Yesterday / earlier today: GlockFour (sparkle), LeadFour (lead line), DropFour (the landing). TomTwo is the handshake *between* sections, not the drop itself.
